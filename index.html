hAI · MarkItDown MCP
MarkItDown MCP Server als Portainer Stack für das highfishNetwork

Multi-Format zu Markdown Konvertierung

Der hAI · MarkItDown MCP Server konvertiert nahtlos verschiedene Dateiformate in Markdown, perfekt für die Integration in KI-Clients und Automatisierungsszenarien.

🚀 Schnellstart

Starten Sie den MarkItDown MCP Server in Sekunden:

git clone https://github.com/jbkunama1/hAI.markitdownMCP.git
cd hAI.markitdownMCP
docker compose up -d

Zugriff: http://localhost:3333/mcp
